- File Analysis
	- We will use oledump.py to conduct static analyis on a potentially malicioius Excel doc in this lab
	- Oledump.py is a python tool that analyzes OLE2 files, aka Structured Storage or Compound File Binary Format
		- OLE stands for Object Linking & Embedding and is a propietary technology developed by Microsoft
		- The file types are used for storing multiple data types (docs, spreadsheets, presentations, etc all within a single file)
			- Tool is useful for extracting/examining the contents of the files making it valuable for forensic analysis & malware detection
	- In the lab
		- Run it on the file by doing the following format `oledeump.py file.xlsm`
		- Output of A (index) +Numbers are called data streams
		- Output of M means macro
		- --vbadecompress for VBA format to be redable
- Fake Network to Aid Analysis
	- **Purpose:** Safely analyze malware that requires network access.
	- **Prevents:** Malware from contacting the real Internet/C2 servers.
	- **Simulates:** DNS, HTTP/HTTPS, FTP, SMTP, etc.
	- **Main tool:** **INetSim**
	- **Captures:** DNS queries, URLs, HTTP requests, downloads, C2 attempts, and network activity.
	- **Basic flow:** `Malware → Fake Network → Simulated Service → Logs`
	- **Use case:** Observe what malware _tries_ to communicate with without allowing real-world communication.
	- **Key benefit:** Network-dependent malware can still execute its behavior for analysis in an isolated environment.
- Memory Investigation: Evidence Pre-processing
	- **Purpose:** Prepare and preserve digital evidence before analysis.
	- **Evidence preprocessing:** Collect, preserve, and organize evidence while maintaining its **integrity**.
	- **Memory (RAM):** Volatile evidence that can contain:
	    - Running processes
	    - Network connections
	    - Loaded DLLs/modules
	    - User activity
	    - Credentials/secrets
	    - Malware artifacts
	- **Volatile data:** Can disappear when a system is shut down or restarted.
	- **Memory acquisition:** Capture RAM **before** shutting down the system when possible.
	- **Evidence integrity:** Use **hashes** to verify that acquired evidence has not been modified.
	- **Chain of custody:** Document who collected, handled, transferred, and analyzed evidence.
	- **Key principle:** **Preserve first, analyze second.**
	- **Common memory-analysis tool:** **Volatility** — analyzes captured memory images.
