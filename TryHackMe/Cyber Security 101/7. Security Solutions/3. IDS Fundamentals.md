- What is and IDS
	- **Firewall:** Protects the network boundary by checking incoming/outgoing connections and blocking traffic that violates rules.
	- **IDS (Intrusion Detection System):** Monitors network traffic **inside the network** for malicious or abnormal activity that gets past the firewall.
	- IDS uses:
	    - **Signature-based detection**: Looks for known attack patterns.
	    - **Anomaly-based detection**: Looks for unusual/abnormal behavior.
	- When suspicious activity is detected, the IDS **generates an alert** for security administrators.
	- **IDS does NOT block or stop the attack**; it only detects and reports it.
	**Analogy:**  
	- `Firewall = Gatekeeper` → `IDS = Security cameras inside the building`
- Types of IDS
	- Deployment Modes
		- Host Intrustion Detection System
			- Host specific
			- Resource intensive & management intensive since per host
		- Network Intrusion Detection System
			- Monitor using the network traffic of all the hosts involved 
			- Provides a centralized view of all detections made within the whole network
	- Detection Modes
		- Signature-Based IDS
			- Rely on signatures 
			- Detect based on previously learned patterns
			- Vulnerable to a 0-Day attack
			- Can detect threats quickly, while others take time
		- Anomaly-Based IDS
			- Learns first the normal behavior (baseline) of the network/system and performs detections if there is a deviation from that baseline
			- Can detect 0 day attacks
			- Vulernable to false positives, but is able to be fine-tuned
		- Hybrid IDS
			- Combines both of the above to use strengths of each
- IDS Example: Snort
	- Background
		- Snort is one of the mostly widely used open-source IDS solutions (1998)
		- Uses signature-based and anomaly-based detections to identify threats
		- Supports custom rules based on custom requirements to detect specific traffic
		- Ability to disable built-in detection rules
	- Modes of Snort
		- **Packet Sniffer Mode**
		    - Reads and displays network packets.
		    - Does **not** analyze or detect threats.
		    - Useful for network monitoring and troubleshooting.
		- **Packet Logging Mode**
		    - Captures and saves network traffic as **PCAP files**.
		    - Used for later analysis and forensic investigations.
		    - Helps determine the root cause of past attacks.
		- **NIDS Mode** (Network Intrusion Detection System mode)
		    - Monitors network traffic **in real time**.
		    - Compares traffic against Snort **rules/signatures**.
		    - Generates alerts when suspicious activity is detected.
		    - **Primary mode for using Snort as an IDS.**
		- **Remember:**  
			- `Sniffer = View` → `Logger = Save` → `NIDS = Detect & Alert`
- Snort Usage
	- Rule Format
		- **Action** → What happens when the rule matches.
		    - Example: `alert`
		- **Protocol** → Protocol being monitored.
		    - Example: `icmp`
		- **Source IP** → IP address traffic originates from.
		    - `any` = any source
		- **Source Port** → Port traffic originates from.
		    - `any` = any port
		- **Destination IP** → Target IP.
		    - $HOME_NET = network defined in Snort configuration
		- **Destination Port** → Port traffic is targeting.
		    - `any` = any port
		- **Rule Metadata** → Information inside parentheses:
		    - **msg** → Alert message
		    - **sid** → Unique Signature ID for the rule
		    - **rev** → Rule revision number; increment when modified
		- Ex Rule: `alert icmp any any -> 127.0.0.1 any (msg:"Loopback Ping Detected"; sid:10003; rev:1;)`

		- Useful for **forensic investigation** and finding signs of intrusion.
