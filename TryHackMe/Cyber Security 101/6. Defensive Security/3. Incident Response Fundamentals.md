- Introduction
	- Cyber attacks are referred to as "Cyber Security Incidents"
	- Incident Response handles an incident from it's start to end
- What are Incidents
	- Processes run on devices and are generally in huge numbers
	- Events are ingested into security solutions as logs and the security solutions can find harmful activities from them
	- When a security solution then finds an eve/group of events associated with a possible malicious activity it triggers an alert
	- Security team analyzes these alerts (False positives vs True Positives)
		- **False positive:** A security solution raised an alert on a high amount of data being transferred from one system to an external IP address. Upon analyzing this alert, the security team found that the subject system was undergoing a backup process to a cloud storage service, which caused this. This is known as a false positive.
		- **True Positive:** A security solution raised an alert on a attempt on one of the organization’s users. Upon analyzing this alert, the security team found that the email was a phishing email sent to this user to compromise the system. This is known as a true positive.
	- True positive alerts are aka Incidents
		- These are given a severity level and ranked by priority
- Types of Incidents
	- Malware Infections
	- Security Breaches
	- Data Leaks
	- Insider Attacks
	- Denial Of Service Attacks

- Incident Response Techniques
	- Very hard to look for abnormal behavior and identify incidents manually
	- There are multiple security solutions that help with this
		- Some of the solutions:
			- **SIEM:** The Security Information and Event Management Solution (SIEM) collects all important logs in one centralized location and correlates them to identify incidents.
			- **AV:** Antivirus (AV) detects known malicious programs in a system and regularly scans your system for these.
			- **EDR:** Endpoint Detection and Response (EDR) is deployed on every system, protecting it against some advanced-level threats. This solution can also contain and eradicate the threat.
	- Steps will be different by type of incident. In this case step-by-step instructions to deal with each type of incident saves time
		- This is known as a "Playbook"
			- Playbooks are the guidelines for an incident
		- Runbooks
			- Different from playbooks and are instead the detailed, step-by-step execution of specific steps during different incidents
