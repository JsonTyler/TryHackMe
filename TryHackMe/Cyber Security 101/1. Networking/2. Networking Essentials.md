- DHCP: Give Me My Network Settings
	- Accessing a network requires configuration of these 3 things:
		- IP address along w/ subnet mask
		- Router (or gateway)
		- DNS server
	- DHCP (Dynamic Host Configuration Protocol):
		- An automated way to configure connected devices
		- An application-level protocol that relies on UDP (Ex: smartphone/laptop configured by default)![[Pasted image 20260927105421.png]]
		- The destination IP address that a client uses when it sends a DHCP Discover packet is 255.255.255.255
		- The source IP address that a cluent uses when getting IP network configuraitno over DHCP is 0.0.0.0
- ARP: Bridging Layer 3 Addressing to Layer 2 Addressing
	- ARP stands for Address Resolution Protocol and is what makes it possible to find the MAC address of another device on the Ethernet
	- Using `tcpdump` will have the packets displayed differently using ARP Request and ARP Reply which is not encapsulated within a UDP or IP packet but instead within an Ethernet frame
	- The destination MAC address used in an ARP Request is ff:ff:ff:ff:ff:ff
	- ARP is considered Layer #2 because it deals with MAC addresses
- ICMP: Troubleshooting Networks
	- ICMP stands for Internet Control Message Protocol and is mainly used for network diagnostics and error reporting
	- Two popular commands:
		- ping: tests connectivity to a target system and measures the rout trip time (RTT)
		- traceroute: discovers the route from your host to the target
	- TTL: The internet protocol has a field called Time-to-Live that indicates the max number of routers a packet can travel through before it is dropped
		- Time is measured in the # of routers not seconds

- NAT
	- NAT stands for Network Address Translation and is one solution to address depletion for IPs
		- To simply the idea it is using one public IP address to provide Internet access to many private IP addresses
		- Unlike routing, NAT supported routers must find a way to track ongoing connections (router does this by maintaining a table of connection maps)
