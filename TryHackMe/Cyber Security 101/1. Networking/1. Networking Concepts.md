- OSI Model
	- The OSI model is the Open Systems Interconnection model
		- It's a conceptual model developed by the International Organization for Standardization (ISO) that describes how communications should occur in a computer network
		- Defines framework for computer network communications
		- Model is theoretrical
		- Aka "Please do not throw spinach pizza away"
		- Has 7 levels:
			- (Layer 1) Physical Layer
			- (Layer 2) Data Link Layer 
				- To put it simply it is an agreement between the different systems on the same network segment on how to communicate
			- (Layer 3) Network Layer
				- To put it simply is concerned with sending data between different networks (logical addressing & routing)
				- Examples: 
					- Internet Protocol (IP)
					- Internet Control Message Protocol (ICMP)
					- Virtual Private Network protocols(VPN):
						- IPSec
						- SSL/TLS VPN
			- (Layer 4) Transport Layer
				- To put it simplty it enables end-to-end communication between running applications on different hosts
				- Examples:
					- Transmission Control Protocol (TCP)
					- User Datagram Protocol (UDP)
			- (Layer 5) Session Layer
				- To put it simply is is responsible for establishing/maintaining/syncing comms between applications running on different hosts
				- Examples:
					- Network File System (NFS)
					- Remote Procedure Call (RPC)
			- (Layer 6) Presentation layer
				- To put it simply it ensures the data is delivered in a form the application layer #7 can understand
				- Handles: 
					- data encoding
					- compression
					- encryption
				- Examples:
					- ASCII
					- Unicode
				- Something else is it uses standards:
					- Images: JPEG, GIF, PNF
					- Email: MIME (Multipurpose Internet Mail Extensions) uses ASCII
			- (Layer 7) Application Layer
				- To put it simply it provides network services directly to end-user applicaitons
				- Top layer
				- Examples:
					- HTTP
					- FTP
					- DNS
					- POP3
					- SMTP
					- IMAP

- IP Addresses and Subnets
	- Definition: To put it simply every host on a network needs a unique identifier for other computers/hosts to be able to communicate with it without ambiguity
		- This is assigned via an IP address for all connected devices to a network
	- An IP Address is composed of the following![[Pasted image 20260926225247.png]]
		- 0 is reserved for the network address (ex: 192.168.1.0) 
		- 255 is reserved for the broadcast address (ex: 192.168.1.255)
			- Sending to a broadcast address targets all the hosts on the network
	- Windows CLI IP Address: 
		- ipconfig
	- Linux/Unix:
		- ifconfig
		- ip address show
		- ip a s
	- Two types of IP Addresses
		- Public
		- Private![[Pasted image 20260926230335.png]]

- UDP & TCP
	- They are two transport protocols to enable processes on networked hosts to communicate
	- UDP (User Datagram Protocol)
		- Allows us to reach a specific process on the targets host
		- A simple connectionless protocol that operates at transport layer (#4)
		- Does not provide a mechanism to know that the packet was delivered
		- Example:
			- Similar to standard mail that has no delivery confirmation but is cheap (UDP) vs fedex which has delivery confirmation but more money (TCP)
		- For UDP the cheaper cost analogy applies via bettwer speed than a transport protocol that provides "confirmation"
	- TCP (Transmission Control Protocol)
		- It's a connection oriented transport protocol
		- Uses various mechanisms to ensure reliable data delivery
		- Layer 4 prototocl
		- Connection must exist before data can be sent
		- Requires a 3 way handshake
- Encapsulation
	- To put it simply it referes to the process of every layer adding a header (and sometimes trailer) to the received unit of data and sending the encapsulated unit to the layer below![[Pasted image 20260926231744.png]]
	- What do you call the UDP data unit that encapsualtes the application data: datagram
	- What do you call the data unit that encapsulates the application data sent over TCP: segment
	- On a wifi, within what will an IP packet be encapsulated: frame
