- Introduction:
	- Nmap is an open-source network scanner that was 1st published in 1997
	- It allows us to:
		- Discover other live devices on this network or oether networks
		- Find running services on the live hosts
- Host Discovery: Who is Online
	- Should be run as root or sudo or will restrict the abilities
	- Nmap uses multiple ways to specify it's targets:
		- IP range using `-`
		- IP subnet using `/`
		- Hostname
		- -sn which is ping scan
	- Scanning a "local" network
		- We can see the MAC addresses of devices 
		- We can find out the network card vendors
		- Able to send ARP requests
	- Scanning a "remote" network
		- Remote means that at least one router separates our system from this network
			- Meaning all our traffic to the target systems must go through 1 or more routers
			- We cannot send ARP requests to the target
	- List scan:
		- command is `-sl`
		- This scan only lists the targets to scan w/o actually scanning them

- Version Detection: Extract More Information
	- OS Detection
		- You can enable OS detection by adding the `-o` option
			- Triggers Nmap to rely on various indicators to make an educated guess about the target operating system
	- Service & Version Detection
		- `-sv` enables version detection
		- Convenient for fathering more info about the target
		- `-A` option enables OS detection, version scanning, traceroute, etc
	- Forcing the Scan
		- When running a port scan there is a possibility the target host does not reply during discovery phase which causes Nmap to mark it as down and won't launch a port scan against it
		- If we want Nmap to treat all hosts as online to scan every port host you can use `-Pn`
- Timing: How Fast is Fast
	- Nmap provides various options to control the scan speed and timing![[Pasted image 20260927173843.png]]
	- Nmap also allows us to control the number of parallel service probes for a host group (UDP and TCP) with `--min-parallelism <numbprobes>` and `--max-parallelism <numprobes>` 
		- By default nmap will automatically control the # of parallel probes
	- Nmap also allows us to control the rate at which nmap sends packets
		- `--min-rate <number>`
		- `--max-rate <number>`
		- in number of packets per second
	- Nmap also allows us to specify the amount of time you are willing to wait (good for slow hosts/network connections)
		- `--host-timeout <time>`
- Output: Controlling What You See
	- Verbosity & Debugging
		- Use `-v` if you want to enable verbose output
			- `-vv` or `-v2` for more verbose
			- `-vvvv` or `-v4` for most verbose
			- Ability to increase verbosity after scan has already started
		- Use `-d` to adjust debugging-level output 
			- max level is `-d9`
	- Saving Scan Report
		- Many format options to save scan results
		- 3 most useful are:
			- normal output (human friendly)
			- XML output
			- grepable output
