- Gobuster: Introduction
	- What it is
		- An open-source offensive tool written in Gloang
		- Enumerates web directories, DNS subdomains, vhosts, Amazon S3 buckets, & Google Cloud Storage by brute force
			- It does this by using specific wordlists and handling the incoming responses
		- Used for penetration testing & bug bounty hunting & cyber security assessments
		- Lies between the reconnaissance and scanning phases in cyber security
	- Vocab
		- Enumeration: the act of listing all the available resources (whether available or not)
		- Brute Force: act of trying every possibility until a match is found (uses wordlists for this)
	- Overview
		- Included by default in linux distros like Kali 
		- `gobuster --help` gives a list of all commands
		- Help pages has multiple sections
			- Usage: shows syntatc on how to use the command
			- Available Commands: Lists them
			- Flags: These are specific options that we can configure to customize our commands
	- Modes
		- `dns` mode: enumerates dns subdomains.
		- `dir` mode: enumerates directories.
		- `vhost` mode: enumerates virtual hosts.
		- Differences between vhosts and subdomains
			- - `dns` mode uses the DNS services to scan for subdomains using the configured domain and wordlist.
			- `vhost` mode sends web requests using the configured URL and wordlist
- Use Case: Directory & File Enumeration
	- Gobuster has a `dir` mode which allows users to enumerate website directories and their files
		- They are many flags used to fine-tune/format this more (--cookies, --extensions, --headers, etc)
	- Useful when you are performing a penetration test and want to see the directory structure of a website and what files they have
	- Directory structures follow particular conventions allowing them to be susceptible to Brute Force using wordlists
	- Gobuster can scan the website and return status code. These status codes then in turn tell you if you can request the director or not as an outsider
	- Ex command format:  `gobuster dir -u "http://www.example.thm" -w /path/to/wordlist`
	- `-u` and `-w` are required flags for enumeration to work
- Use Case: Subdomain Enumeration
	- Another mode is `dns` mode
	- This mode allows Gobuster to brute force subdomains
	- Format: `gobuster dns --help`
	- How to Use dns Mode
		- To run it you use the following command syntax:
			- `gobuster dns -d example.thm -w /path/to/wordlist`
		- Example: 
			- `gobuster dns -d example.thm -w /usr/share/wordlists/SecLists/Discovery/DNS/subdomains-top1million-5000.txt`
- Use Case: Vhost Enumeration
	- Background
		- This mode allows Gobuster to brute force virtual hosts
		- Difference between vhost and dns mode is the way that Gobuster scans:
			- `vhost` mode will navigate to the URL created by combining the configured HOSTNAME (-u flag) with an entry of a wordlist.
			- dns mode will do a DNS lookup to the FQDN created by combining the configured domain name (-d flag) with an entry of a wordlist.
		- Format for help: `gobuster vhost --help`
		- Uses flags similar to `dir` mode
	- How To Use vhost Mode
		- syntax for command: `gobuster vhost -u "http://example.thm" -w /path/to/wordlist`
		- -u and -w are required for vhost enumeration to work
