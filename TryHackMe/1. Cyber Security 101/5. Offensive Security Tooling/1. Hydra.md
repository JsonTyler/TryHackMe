- Hydra Introduction
	- What is it
		- It is a brute force online password cracking program
		- Can run through a list and "brute force" authentication services
		- Official repo: https://github.com/vanhauser-thc/thc-hydra (Already installed on Kali)
		- Supports following protocols:
			- “Asterisk, AFP, Cisco AAA, Cisco auth, Cisco enable, CVS, Firebird, FTP, -FORM-GET, HTTP-FORM-POST, HTTP-GET, HTTP-HEAD, HTTP-POST, HTTP-, HTTPS-FORM-GET, HTTPS-FORM-POST, HTTPS-GET, HTTPS-HEAD, HTTPS-POST, HTTP-Proxy, ICQ, , , , MEMCACHED, MONGODB, MS-, MYSQL, NCP, NNTP, Oracle Listener, Oracle , Oracle, PC-Anywhere, PCNFS, , POSTGRES, Radmin, , Rexec, Rlogin, Rsh, RTSP, SAP/R3, SIP, , , SMTP Enum, SNMP v1+v2+v3, SOCKS5, SSH (v1 and v2), SSHKEY, Subversion, TeamSpeak (TS2), Telnet, VMware-Auth, VNC and XMPP.”
		- Important not to ever realy on default passwords for cctv, etc
- Using Hydra
	- Hydra Commands
		- The options/parameters we pass into Hydra depend on which service/protocol we're attacking
		- SSH
			- format: `hydra -l <username> -P <full path to pass> 10.65.163.147 -t 4 ssh`
		- Post Web Form
			- format: `sudo hydra <username> <wordlist> 10.65.163.147 http-post-form "<path>:<login_credentials>:<invalid_response>"`
