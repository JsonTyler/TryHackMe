- Integrating JavaScript in HTML
	- Internal Javascript
		- Refers to embedding the JS code directly within an HTML doc (in `<script>` tags)
	- External Javascript
		- Refers to creating/storing JS code in a separate file ending with a `.js` file extension
		- Helps devs keep the HTML doc clean and organized
	- Verifying Internal or External JS
		- Important to know which for pen-testing
		- Use `View Page Source`
- Abusing Dialogue Functions
	- Built in functions in js for interaction with users are:
		- alert, prompt, confirm
	- Alert: 
		- Displays a dialogue with an "OK" button, typically used for warnings
	- Prompt: 
		- Displays a dialogue box that asks the user for input. Returns user input when user clicks on "OK" button or null if user clicks "Cancel"
	- Confirm:
		- Displays a dialogue with a message and two buttons "OK" and "Cancel"
			- Returns true if user clicks "OK"
			- Returns false if user clicks "Cancel"
	- How Hackers Exploit the Functionality
		- Can disrupt user experience with the above dialogues
- Bypassing Control Flow Statements
	- Refers to the order in which statements and code blocks are executed based on certain conditions
	- Control flow structures: `if-else`, `switch` to make decisions
	- Loops: `for`, `while`, `do...while` to repeat actions
