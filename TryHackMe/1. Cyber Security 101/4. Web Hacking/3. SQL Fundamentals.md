- Databases 101
	- Introducing Databases
		- Databases are an organized collection of structured information /data that is easily accessibile and can be manipulated or analyzed
	- Different Types of Databases
		- Relational databases (SQL)
			- Store structred data meaning the data follows a structure
			- Stored in rows & columns in a table
			- Relationships can be made between two or more tables
		- Non-Relational databases (NoSQL)
			- Stores data in a non-tablular format
	- Tables, Rows, & Columns
		- All data stored in a relational database will be stored in ia table
	- Primary & Foreign Keys
		- There are 2 types of keys:
			- Primary Keys: A primary key is used to ensure that the data collected in a certain column is unique.
			- Foreign Keys: A foreign key is a column (or columns) in a table that also exists in another table within the database, and therefore provides a link between the two tables.
- SQL
	- What is SQL
		- The interaction between the end user and the database can be done using SQL (Structured Query Language)
		- SQL is a programming language that can be used to query, define, & manipulate the data stored in a relational database
	- The Benefits of SQL & Relational Databases
		- SQL is ubiquitous as databases themselves
		- Benefits:
			- Fast
			- Easy to learn
			- Reliable
			- Flexible
- CRUD Operations
	- CRUD statns for Create, Read, Update, Delete
	- Considered the basic operations in any system that manages data
- Clauses
	- Part of a statement that specifies the criteria of the data being manipulated
	- Can help us define the type of data and how it whould be retrieved/sorted
	- Types: DISTINCT, GROUP BY, ORDER BY, HAVING
- Operators
	- Are the way to filter & manipulate data effectively
	- Logical Operators
		- These test the truth of a condition and return a boolean value of TRUE or FALSE
	- LIKE Operator
		- Commonly used in conjunction with "WHERE" in order to filter for specific patterns within a column
	- AND Operator
		- Uses multiple conditions within a query and returns TRUE if all of them are true
	- OR Operator
		- Combines multiple conditions within queries and returns TRUE if at least one of these conditions is true
	- NOT Operator
		- Reverses the value of a boolean operator and allows us to exclude a specific condition
	- BETWEEN Operator
		- Allows us to test if a value exists within a defined
	- Comparison Operator
		- Used to compare values and check if they meet specified criteria
	- Equal To Operator
		- The `=` operator compares two expressions and deterimines if they are equal
	- Not Equal To Operator
		- The `!=` operator comparies expressions and tests if they are not equal
		- Also checks if a value differs from the one within a column
	- Less Than Operator
		- The `<` operator compares if the expression with a given value is lesser than the provided one
	- Greater Than Operator
		- The `>` operator compares if the expression with a given value is greater than the provided one
	- Less Than or Equal To and Greater  Than or Equal To Operators
		- The `<=` (Less than or equal) operator compares if the expression with a given value is less than or equal to the provided one. On the other hand, The `>=` (Greater than or Equal) operator compares if the expression with a given value is greater than or equal to the provided one.
