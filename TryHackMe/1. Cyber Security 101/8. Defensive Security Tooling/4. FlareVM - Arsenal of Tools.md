- Commonly Used Tools for Investigation: Overview
	- Process & System Analysis
		- **Process Explorer** — Investigate running processes and process relationships.
		- **Process Monitor (Procmon)** — Monitor real-time process, file, registry, and network activity.
		- **Autoruns** — Identify programs configured to start automatically.
		- **Process Hacker** — Process and memory monitoring.
	-  Network Analysis
		- **Wireshark** — Capture and analyze network traffic.
		- **Nmap** — Network discovery and port/service scanning.
		- **Netcat** — Read/write data over network connections.
	-  Malware & File Analysis
		- **Ghidra** — Reverse engineering, disassembly, and decompilation.
		- **x64dbg** — Debug x64/x32 binaries.
		- **DIE** — Identify packers, compilers, and cryptors.
		- **CFF Explorer** — Analyze and edit PE files.
		- **HxD** — View and edit binary/hex data.
		- **FileInsight** — Analyze and edit binary files.
	- Memory Forensics
		- **Volatility** — Analyze memory dumps and investigate processes, DLLs, injected code, and other memory artifacts.
		- **Rekall** — Memory forensics and incident response.
	- Disk Forensics
		- **FTK Imager** — Acquire and analyze forensic disk images.

- Analyzing Malicious Files!
	- Static Analysis
		- Analyze a file **without executing it**
		- **PEStudio** — Examine PE files and identify suspicious properties
		- Look for:
		    - Hashes
		    - Imports/functions
		    - Metadata
		    - Suspicious APIs
		    - Packing/obfuscation
		    - Missing or unusual PE headers
	-  FLOSS
		- Extracts strings from executables
		- Useful for finding **obfuscated strings**
		- Can reveal:
		    - URLs/IPs
		    - File paths
		    - Commands
		    - API calls
		    - Other indicators
	- Dynamic Analysis
		- Analyze malware **while it is running**
		- Observe:
		    - Processes
		    - Files created/modified
		    - Registry changes
		    - Network connections
		    - C2 communication
	-  Useful Tools
		- **PEStudio** — Static PE analysis
		- **FLOSS** — Extract strings
		- **Process Explorer** — Investigate processes
		- **Procmon** — Monitor system activity
		- **Wireshark** — Analyze network traffic
	-  Analysis Workflow
		- Identify suspicious file
		- Calculate hashes
		- Perform static analysis
		- Extract strings with FLOSS
		- Execute safely in an isolated environment
		- Monitor processes and system activity
		- Monitor network connections
		- Identify **IOCs** and malicious behavior
	- Key Concept
		- **Static analysis** = What does the file contain?
		- **Dynamic analysis** = What does the file actually do?
