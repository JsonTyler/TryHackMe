- File Analysis
	- We will use oledump.py to conduct static analyis on a potentially malicioius Excel doc in this lab
	- Oledump.py is a python tool that analyzes OLE2 files, aka Structured Storage or Compound File Binary Format
		- OLE stands for Object Linking & Embedding and is a propietary technology developed by Microsoft
		- The file types are used for storing multiple data types (docs, spreadsheets, presentations, etc all within a single file)
			- Tool is useful for extracting/examining the contents of the files making it valuable for forensic analysis & malware detection
	- In the lab
		- Run it on the file by doing the following format `oledeump.py file.xlsm`
		- Output of A (index) +Numbers are called data streams
