- Introduction
	- Background
		- One risk of analyzing malicious software is the risk of our machine/environment being compromised when we run it unless we have a sandbox or completely isolated environment to test it
		- Two types of analysis
			- Dynamic analysis
			- Static analysis
				- CAPA is static
		- CAPA stands for "Common Analysis Platform for Artifacts" and was developed by the FireEye Mandiant team
		- It was designed to identify the capabilitites present in executable files like "Portable Executables (PE)", ELF binaries, .NET modules, shellcode, and even sandbox reports
			- It analyzes the file and applies a set of rules that describe common behaviors which allows it to determine what the program is capable of doing (ex: network communicaiton, file manipulation, process injection)
			- Encapsulates reverse engineering
		- The tool is mainly used in malware analysis and threat hunting
