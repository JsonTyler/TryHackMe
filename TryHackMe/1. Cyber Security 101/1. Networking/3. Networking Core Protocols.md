- DNS: Remembering Addresses
	- DNS stands for Domain Name System and is responsible for properly mapping a domain name to an IP address
		- Operates in Layer #7 (Application Layer) of OSI mode
		- Uses port 53 as default with UDP and fallback to TCP
	- Common types of DNS records:
		- A record: maps a hostname to one or more IPV4 addresses
		- AAAA record: same as ^ but for IPV6
		- CNAME record: Canonical name maps a domain name to another domain name
		- MX record: Mail exchange record specifies the mail server responsible for handling emails for a domain
	- Tools:
		- To look up the IP address of a domain name from the CLI you can use `nslookup` 
- WHOIS
	- Whoever registers a domain is granted the power to set the A, AAAA, MX, etc records
	- When you buy a domain name you are required to provide accurate contact info as the registrant
		- This becomes part of the data available via WHOIS records and is available publicly
- HTTP(S): Accessing the Web
	- HTTP & HTTPS are the main protocols that are used in the browser
		- HTTP: Hypertext Transfer Protocol
		- HTTPS: Hypertext Transfer Protocol Secure
			- Relies on TCP and defines how the browser communicates with the web servers
	- Designed to retrieve web pages
	- Common commands the web browser issues to web servers:
		- GET, POST, PUT, DELETE
	- Ports used:
		- HTTP: port 80 (8080)
		- HTTPS: port 443 (8443)
- FTP: Transferring Files
	- FTP is File Transfer Protocl and is designed to transfer files
		- Very efficient (higher speeds than HTTP)
		- Common commands: 
			- USER: username
			- PASS: password
			- RETR: download a file from FTP server to client
			- STOR: upload a file from the client to the FTP server
	- FTP server listens on TCP port 21 by default
- SMTP: Sending Email
	- SMTP is `Simple Mail Transfer Protocol` and defines how a mail client talks with a mail server and how a mail server talks with another
- POP3: Receiving Email
	- POP3 is the `Post Office Protocol version 3` and is designed to allow the client to communicate with a mail server and retrieve email messages
	- Email client sends via SMTP and retrieves using POP3
	- POP3 server listens on TCP port 110 by default
- IMAP: Synchronizing Email
	- IMAP stands for `Internet Message Access Protocol` and is a protocl that allows syncing of messages instead of deleting a message after retrieving it
	- Allows synchronizing read, moved, and deleted messages
	- IMAP server listens on TCP port 143 by default
