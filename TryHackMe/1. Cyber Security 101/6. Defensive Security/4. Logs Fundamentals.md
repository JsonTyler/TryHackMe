- Introduction to Logs
	- Background
		- Important source of info during an investigation
		- Traces ot put pieces together
		- Logs are the digital footprints left behind by any activity
			- Could be normal or malicious
	- Use Cases of Logs
		- Security Events Monitoring: Logs help us detect anomalous behavior when real-time monitoring is used
		- Incident Investigation & Forensics: Logs are the traces of every kind of activity. Offers detailed info on what happened during an incident. The security team will use the logs to perform root cause analysis of incidents
		- Troubleshooting: Logs also record errors in systems/apps and can be used to diagnose issues and are helpful in fixing them
		- Performance Monitoring: Logs can provide insights into the performance of applications
		- Auditing & Compliance: Logs play a major role in Auditing & Compliance since they make it easier to establish a trail of different kinds of activities

- Windows Event Logs Analysis
	- Windows OS logs many activities that take place
		- The logs are stored in segregated log files within a specific log category
		- Some crutial types on Windows:
			- **Application:** There are many applications running on the operating system. Any information related to those applications is logged into this file. This information includes errors, warnings, compatibility issues, etc.
			- **System:** The operating system itself has different running operations. Any information related to these operations is logged in the System log file. This information includes driver issues, hardware issues, system startup and shutdown information, services information, etc.
			- **Security:** This is the most important log file in Windows OS in terms of security. It logs all security-related activities, including user authentication, changes in user accounts, security policy changes, etc.
		- Windows OS has a utility known as "Event Viewer" used to view the logs in a GUI with a search function
		- Windows event log is comprised of different pieces:
			-  **Description:** This field has a detailed information of the activity.
			- **Log Name:** The Log Name indicates the log file name.
			- **Logged:** This field indicates the time of the activity.
			- **Event ID:** Event IDs are unique identifiers for a specific activity.

- Web Server Access Logs Analysis
	-  **Access logs:** Record website requests, including IP, timestamp, method, URL, status code, and User-Agent.
	- **`cat`:** View or combine log files.
	- **`grep`:** Search logs for specific strings/patterns.
	- **`less`:** View large logs page-by-page and search within them.
	    - `Space` = next page
	    - `b` = previous page
	    - `/pattern` = search
	    - `n` / `N` = next/previous match
	- Logs are commonly rotated into separate files for different time periods
